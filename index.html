Prototype assumptions & limitations

  • This page simulates the detection logic with adjustable sensor values, not the STM32 CPU.
  • MPU-6050 is represented by controllable tilt/acceleration values; it is not a device-level I²C model.
  • ESP8266 connectivity and cloud upload are status demonstrations only; no Wi‑Fi connection or cloud request is made.
  • Use a proper regulated 3.3 V supply. ESP-01 can draw current peaks that a weak regulator cannot supply.
  • Check the actual Blue Pill clone pin labels and the MPU-6050 breakout voltage tolerance before wiring.
